# Credit by Isa

Deployable MVP for Credit by Isa.

## Render
Build command:
`pip install -r requirements.txt`

Start command:
`uvicorn main:app --host 0.0.0.0 --port $PORT`

This MVP includes the dashboard, ISA Progress, Funding Readiness, Action Plan,
Dispute Center, membership overview and Admin Center preview.

Important: payments, certified mail, bureau integrations, AI chat, MFA and
production-grade authentication/storage are placeholders and must be connected
before a public production launch.
